# Roadmap

Planned features and improvements for Rewire.

This roadmap reflects the current direction for Rewire. Priorities may shift based on user feedback and real-world needs. Nothing here is a commitment — items may change, be reordered, or be dropped entirely.

Have a feature request? Reach out at [hello@rewire.run](mailto:hello@rewire.run).

## [In progress](https://docs.rewire.run/roadmap#in-progress)

### [Windows support](https://docs.rewire.run/roadmap#windows-support)

Bringing Rewire to Windows for cross-platform development workflows. This includes:

- Windows x86\_64 binary builds.
- Install script for PowerShell.
- DDS discovery on Windows network stacks.
- CI/CD validation on Windows.

## [Planned](https://docs.rewire.run/roadmap#planned)

### [Edge deployment](https://docs.rewire.run/roadmap#edge-deployment)

Run Rewire on resource-constrained devices like NVIDIA Jetson, Raspberry Pi, and other embedded platforms. Focus areas:

- Reduced memory footprint for limited RAM environments.
- ARM 32-bit support (current aarch64 builds already work on Jetson).
- Broader CPU/bandwidth controls, building on the [per-topic rate caps](https://docs.rewire.run/configuration/topic-filtering#throttling-high-rate-topics) shipped in v0.7.0.
- Selective topic streaming to minimize network usage on metered connections.

### [Rerun Data Platform integration](https://docs.rewire.run/roadmap#rerun-data-platform-integration)

Stream live data directly to cloud-hosted [Rerun Data Platform](https://rerun.io) instances, for fleet-wide analytics and long-term storage.
