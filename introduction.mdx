Rewire connects to your ROS 2 network via DDS and Zenoh, discovers topics automatically, and streams them to [Rerun](https://rerun.io) for real-time visualization. It's a single Rust binary — no `rclcpp`, no `setup.bash`, no colcon workspaces. The bundled Rewire Viewer extends the official Rerun viewer with ROS 2-specific panels (Topics, Nodes, Diagnostics), though Rewire streams equally well to any Rerun viewer you already have running.

## From zero to viewer in two commands

Install Rewire with the one-line install script, then start streaming:

```bash
curl -fsSL https://rewire.run/install.sh | sh
rewire record
```

The install script places both `rewire` (the bridge) and `rewire-viewer` in `~/.local/bin`. Once installed, `rewire record` launches the Rewire Viewer and begins receiving every topic discovered on your network. To stream into a viewer running on another machine, pass `--connect host:9876` instead.

<Note>
  The one exception to the no-ROS-install rule is URDF mesh resolution. If you visualize a robot model with `package://` mesh URIs, source your ROS 2 environment so `AMENT_PREFIX_PATH` is set before running Rewire.
</Note>

## Key features

<CardGroup cols={2}>
  <Card title="Zero ROS 2 install" icon="box">
    Rewire is a standalone Rust binary. It observes DDS and Zenoh traffic passively — it is never a ROS 2 node and never interferes with your ROS graph.
  </Card>
  <Card title="Automatic topic discovery" icon="radar">
    Topics are discovered and subscribed automatically as they appear. New topics are picked up live, and Rewire unsubscribes cleanly when topics go away.
  </Card>
  <Card title="Flexible install methods" icon="wrench">
    Choose from an install script, pixi, APT (Debian/Ubuntu), or Nix. All methods deliver the same binaries for macOS (Apple Silicon) and Linux (x86_64, aarch64).
  </Card>
  <Card title="Built-in type mappings" icon="map">
    Common ROS 2 message types map to Rerun archetypes out of the box. Extend or override any mapping via a JSON5 config file — no code required.
  </Card>
</CardGroup>
